# Horizonte — Projetos de mestrado

App estático para explorar três perfis de orientação, gerar propostas e comparar temas.

Abra index.html no navegador. Não requer dependências. Projetos salvos ficam no armazenamento local; o comparador utiliza regras de afinidade, sem serviço externo de IA.

Fontes institucionais e limitações da pesquisa estão indicadas na interface.
